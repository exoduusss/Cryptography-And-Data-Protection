# Cryptographic References & Standards

This project implements architectures and algorithms derived from the following canonical references:

1. **Horst Feistel (1973)**:
   *Cryptography and Computer Privacy*. Scientific American, 228(5), 15-23.
2. **NIST FIPS 197**:
   *Advanced Encryption Standard (AES)*. National Institute of Standards and Technology.
3. **NIST SP 800-38A**:
   *Recommendation for Block Cipher Modes of Operation: Methods and Techniques*.
4. **Trevor Perrin & Moxie Marlinspike (2016)**:
   *The Double Ratchet Algorithm*. Signal Foundation. [https://signal.org/docs/specifications/doubleratchet/](https://signal.org/docs/specifications/doubleratchet/)
5. **Moxie Marlinspike & Trevor Perrin (2016)**:
   *The X3DH Key Agreement Protocol*. Signal Foundation. [https://signal.org/docs/specifications/x3dh/](https://signal.org/docs/specifications/x3dh/)
6. **RFC 5869**:
   *HMAC-based Extract-and-Expand Key Derivation Function (HKDF)*. H. Krawczyk, P. Eronen.
7. **RFC 7748**:
   *Elliptic Curves for Security (Curve25519 and Curve448)*. A. Langley, M. Hamburg, S. Turner.
8. **RFC 8032**:
   *Edwards-Curve Digital Signature Algorithm (EdDSA / Ed25519)*. S. Josefsson, I. Liusvaara.
9. **RFC 8439**:
   *ChaCha20 and Poly1305 for IETF Protocols*. Y. Nir, A. Langley.
10. **Pascal Paillier (1999)**:
    *Public-Key Cryptosystems Based on Composite Degree Residuosity Classes*. EUROCRYPT 1999, LNCS 1592, pp. 223–238. Springer-Verlag.
